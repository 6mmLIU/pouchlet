Common questions

Why does Pouch ask to allow a folder?

Mac App Store apps can only touch what you give them. To extract next to an archive, Pouch needs that folder, so it asks once and remembers. To be asked less, choose a folder higher up, such as your home folder. Manage these in Settings › General › Folder Access.

The Finder menu doesn’t show up.

Turn on Settings › Extensions › Finder Context Menu, then allow “Pouch” when System Settings opens (General › Login Items & Extensions).

Space doesn’t preview archives.

Turn on Settings › Extensions › Preview archives with Space. If the preview’s buttons don’t open Pouch, allow “Pouch” under Login Items in System Settings.

File names look garbled.

Pouch detects Chinese, Japanese and Korean names from Windows automatically. If one still looks wrong, open the archive and pick another encoding from the toolbar’s encoding menu.

Can Pouch create RAR files?

No. RAR is a licensed format; Pouch can open and extract it but not create it. Use 7Z or ZIP instead.

常见问题（简体中文）

遇到问题或有建议？请在 GitHub 上提交 issue，并附上 macOS 版本和压缩包类型。

为什么 Pouch 会请求允许访问文件夹？

App Store 应用只能使用你交给它的文件。解压到压缩包旁边需要那个文件夹的权限，所以 Pouch 会询问一次并记住。选择更上层的文件夹（比如个人文件夹）就能少被询问。可在“设置 › 通用 › 文件夹访问权限”中管理。

“访达”右键菜单里没有 Pouch？

在“设置 › 扩展”中打开“访达右键菜单”，然后在弹出的“系统设置”中允许“Pouch”。

按空格不能预览压缩包？

在“设置 › 扩展”中打开“按空格预览压缩包”。如果预览里的按钮打不开 Pouch，请在“系统设置”的“登录项”中允许“Pouch”。

文件名乱码？

Pouch 会自动识别来自 Windows 的中日韩文件名；如果仍有乱码，可在工具栏的编码菜单中换一种编码。
